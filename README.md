Network Scanning and Information Gathering using Zenmap & Kali Linux

📌 Project Overview

This project focuses on understanding the fundamentals of network scanning, host discovery, and information gathering using Zenmap (Nmap GUI) and Kali Linux.

The project was completed as a hands-on cybersecurity learning activity to explore network scanning techniques, identify active hosts, examine IP and MAC addresses, and understand open ports and services.

A detailed project report has also been prepared, documenting the practical work, commands used, observations, challenges, and learning outcomes.

🎯 Objectives

- Understand the basics of network scanning and reconnaissance.
- Identify live hosts within a network.
- Discover IP and MAC addresses.
- Explore open ports and service detection.
- Practice essential Kali Linux commands.
- Understand network configuration and troubleshooting.

🛠️ Tools & Technologies Used

- Kali Linux – Linux-based cybersecurity environment.
- Zenmap – Graphical interface for Nmap.
- Nmap – Network scanning and host discovery tool.
- Oracle VirtualBox – Virtualization platform.

 🔍 Practical Work Performed

 1. Zenmap (Nmap GUI)

- Performed network scans.
- Discovered active hosts.
- Identified IP and MAC addresses.
- Explored open ports and services.
- Practiced different scanning techniques.

 2. Kali Linux Commands

The following commands were explored and practiced:

nslookup: DNS lookup and domain information 
whois: Domain registration information 
curl: Sending URL requests and retrieving web content 
ping: Checking network connectivity 
ip add: Displaying IP addresses and network interfaces 
nmap: Network scanning and port discovery 

💡 Challenges Faced & Solutions

During the practical implementation, I encountered a network configuration issue where Zenmap initially detected only one active host instead of the expected multiple hosts.

I investigated the network settings, performed troubleshooting, and successfully resolved the issue to complete the scanning process.

This experience helped me understand the importance of network configuration and problem-solving in cybersecurity.

 📚 Key Learning Outcomes

- Understanding network scanning and host discovery.
- Learning basic network reconnaissance concepts.
- Working with Kali Linux command-line tools.
- Understanding DNS and domain information lookup.
- Identifying network hosts, ports, and services.
- Developing practical troubleshooting skills.
